# CS151 Multi-Model AI Study Assistant

A multi-model AI study assistant for the CS151 project.

## Project status

The team is currently in the setup and planning phase. Week 1 focuses on establishing the GitHub repository, agreeing on a collaboration workflow, and documenting project progress. Application features have not been implemented yet.

## Team workflow

- `main`: stable branch for reviewed work.
- `dev`: shared integration branch.
- `feature/<short-description>`: individual work branches.
- Use GitHub Issues to describe and track tasks.
- Open a Pull Request (PR) to merge work into `dev`.
- Review and test changes before merging.
- Merge `dev` into `main` when the team considers the work stable.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution process.

## Documentation

Weekly progress reports and project planning documents are kept in the `docs/` directory.
